IQ 信号分析与回放软件 - 便携版
================================

启动方法
--------
双击 IQAnalyzer.exe。请勿只复制 EXE，必须保留整个 IQAnalyzer_Portable 文件夹。

数据目录
--------
1. 可将 IQ 数据放入 data 文件夹。
2. 数据量较大时，无需复制，直接在软件界面中选择外部数据目录。
3. 当前软件项目的原始数据约 12.75 GB，因此未包含在便携包中。

输出目录
--------
分析结果、频谱特征数据库和重构数据默认保存在 output 文件夹。

设备连接
--------
便携包包含 PyVISA 和 PyVISA-py，可直接尝试 TCP/IP VISA 地址。
若使用 USB、GPIB 或厂商专用接口，目标电脑仍可能需要安装对应仪器的 VISA/USB 驱动。

系统要求
--------
64 位 Windows 10 或 Windows 11。不需要安装 Python。
