# 电磁环境数据分析软件

这个小工具用于读取 `data` 文件夹中的 Rohde & Schwarz `IQR-WV` IQ 数据：

- 自动识别同名的 `.ws1/.ws2/.wsm` 文件；
- 解析文件头里的采样率、采样点数、参考电平；
- 将 `.ws1` 和 `.ws2` 当作连续 volume 读取；
- 按需抽样读取大文件，不会一次性加载 1.5 GB 文件；
- 输出时域图、星座图、PSD 频谱、频谱图、幅度分布和统计摘要。

## 运行 GUI

在 `software` 目录下运行：

```powershell
python .\iq_analyzer\iq_analyzer_gui.py
```

也可以直接双击：

```text
iq_analyzer\run_gui.bat
```

软件包含六个独立模块：`IQ 数据`、`环境频谱`、`场景分类`、`频谱特征库`、`信号重构`和`设备回放`。

界面里选择 IQ 数据组、时间范围和图类型，点击“生成并查看”。程序会在右侧标签页中直接绘图：

- `摘要`：读取到的基本参数和统计结果；
- `时域`：I/Q、幅度、相位时域图；
- `星座图`：IQ 星座散点图；
- `频谱`：PSD 频谱；
- `时频图`：信号随时间变化的频谱；
- `直方图`：幅度分布；
- `日志`：运行信息。

这些图不是贴入的 PNG，而是嵌入式 Matplotlib 图窗，可以用图上方工具栏缩放、平移、回到初始视图或另存图片。

## 频谱特征库

打开“频谱特征库”模块，点击“扫描全部测点并建立特征库”。程序会对每个城市、测点、极化方式和频段完成跨扫描文件最大值保持，再提取：

- 峰值场强及峰值频率；
- 均值、中位数、P95、P99、标准差和动态范围；
- 频谱质心、背景场强、强信号频点占比；
- 强峰数量和场强最高的主要峰频点。

结果保存在 SQLite 数据库：

```text
iq_analyzer\output\spectrum_feature_library.db
```

数据库同时压缩保存各测点最大值保持频谱。使用城市、极化、频段和测点关键字筛选后，在表格中按住 `Ctrl` 或 `Shift` 选择 2 至 12 个位置，点击“对比所选测点”，即可查看频谱叠加、峰值/P95、强信号占比、相关系数和 RMS 场强差。原始频谱数据发生变化后，再重新建库即可更新已有记录。

## 场景分类

“场景分类”模块按照采集方案和 T/CSAE 典型场景组织采集地点，包括工业区、闹市区、居民区、大型停车场、购物广场、地铁站、机场区域、医院外部、短波电台、基站、广播电视塔、发电站、智能网联示范区等类别。

首次运行时，软件根据地点名称生成初始分类建议。选择场景类型即可列出该场景中的地点；选择地点后，可以切换极化方式和频段，查看该地点的频谱特征摘要及最大值保持频谱。分类结果可人工修改并添加备注。

IQ 文件名本身未包含地点信息，因此场景模块提供“地点-IQ 数据”人工关联功能。场景分类和 IQ 关联关系都保存在 `spectrum_feature_library.db` 中，不移动、不重命名、不修改原始频谱 CSV 或 IQ 文件。

也可以使用“生成可填写的关联表”导出 CSV，在 Excel 中填写后点击“导入填写好的关联表”批量建立关系。当前模板为 `场景地点_IQ关联表_更新版.csv`，列格式为：

```text
序号,城市,地点,场景类型,频谱数据目录名称,IQ数据相对目录,IQ数据组名称,备注
```

`IQ数据组名称`既可以填写完整主文件名，也可以填写同一地点所有文件的公共前缀。程序会扫描IQ根目录，自动关联所有以前缀开头且同时具有 `.wsm/.ws1/.ws2` 的完整数据组。表格末尾也可以添加新地点；频谱数据通过“频谱数据目录名称”映射到原始测点文件夹。

结果也会同步保存到：

```text
iq_analyzer\output\<recording_name>\
```

## 典型信号筛选与信号重构

“信号重构”模块中的“频谱-IQ对应表”按采集地点将频谱特征库的主要峰值与关联 IQ
数据组进行汇总，每个地点只占一行。多个频谱峰值、峰值功率、3 dB 带宽、IQ 中心频率
和 IQ 数据组名分别在对应单元格中按逗号分隔，并保持相同顺序。IQ 中心频率优先取数据
组文件名中的最后一个数值，例如 `...95m` 识别为 95 MHz。生成结果会写入主关联表
`场景地点_IQ关联表_更新版.csv`右侧新增的分析列，原有地点、目录、前缀和备注列保持
不变；首次更新前自动生成`场景地点_IQ关联表_更新版_分析前备份.csv`。下次启动软件会
直接读取主关联表，重新生成时才扫描频谱特征库和当前 IQ 根目录。移动硬盘离线时，
数据库中已有的关联记录仍会保留并标记为离线。

IQ 数据组匹配要求完整文件名满足“关联表前缀 + 数字中心频率 + 可选 `m`”，并且同目录
同时存在 `.wsm/.ws1/.ws2`。该规则可避免短前缀串联其他地点，例如 `cims` 不会匹配
`cims2hao...`。不满足规则的孤立文件或不完整三件套不会自动归属到任何地点。

“场景IQ代表选择”用于从同一场景的重复采集中快速确定回放候选。软件按用户设置的中心
频率容差对 IQ 分组，默认相差不超过 20 MHz 视为相似频段；每个文件在 10%、50%、90%
位置读取短窗口估算功率，每个频段只保留功率最大的一组。结果列出频段、中心频率、地点、
IQ 数据组、功率和推荐片段起点，可导出 CSV，也可双击结果直接带入“实际采集典型场景
信号重构”。该过程只读取少量样本，不修改原始 IQ 文件。

重构操作采用两阶段界面。“信号选择”页面只显示频谱-IQ关联、场景IQ代表和典型频谱信号
的筛选结果；选中代表 IQ 后，点击“使用选中IQ进入实测重构”或双击结果行，软件会切换到
独立的“重构工作台”，自动带入地点、IQ数据组、中心频率、采样率、推荐片段起点和场景
目标场强。实测重构中上述来源参数被锁定，不再提供二次选择，只需设置重构时长、循环
平滑时间和目标场强；默认自动读取推荐起点之后的 100 ms 实测片段，循环形成 1000 ms
重构信号。随机种子只在模拟调制、多无线电系统和复杂场景模式中显示。工作台切换重构
方式时只显示当前方式所需的参数，生成摘要和波形预览也集中在该页面，避免筛选表与重构
参数混排。

“信号重构”模块在区域内频率聚类的基础上，进一步将场景出现概率与全部场景的平均出现概率进行对比，输出：

- 公共背景信号；
- 场景常见信号；
- 场景增强信号；
- 场景特有信号。

每个典型信号同时显示场景概率、全局概率、特异性、场强增量、平均 3 dB 带宽和可覆盖该频率的 IQ 候选。移动硬盘未连接时，已关联 IQ 会标记为离线，关联关系仍然保留。

模块支持四种波形生成方式：

1. 实际采集典型场景信号：使用“场景IQ代表选择”的结果，执行去直流、重采样、交叉渐变
   和无缝循环，并按照场景自动给出 6、10、12、15、20 或 120 V/m 的标准目标场强；
2. 单频点调制信号：提供中短波广播、调频广播、RKE/PEPS、数字电视、移动通信、卫星导航、
   蓝牙和 WLAN 模板，支持 CW、AM、FM、ASK、FSK、BPSK、QPSK、16QAM、脉冲和噪声；
3. 多无线电系统合成信号：提供 RKE/PEPS、广播、移动通信和车载无线综合模板，在一个回放
   通道内按频偏、相对电平及调制参数组合，目标总场强可选 30、60、100 或 140 V/m；
4. 复杂场景多信号组合：以选定的实采典型场景 IQ 作为背景，在同一采样带宽内叠加模拟无线
   电系统或干扰信号。跨越多个不连续频段时应分别生成回放通道，由多路信号源同步输出并通过
   功分/合路链路形成复杂场景。

生成结果先在界面显示 I/Q 波形、相对频谱和时频图。重构预览顶部以同一坐标轴叠加显示
I、Q 两路基带采样值，并提供默认 1 ms 窗口的播放、
暂停、停止、窗口长度和进度拖动控件。该播放仅用于观察波形变化，不输出声音或射频。
当“目标回放时长 × 采样率”超过 800 万个复采样点时，软件生成最长 800 万点的循环波形
缓冲区，并在参数文件中同时记录目标回放时长和缓冲区时长；实验室回放时按目标时长循环
输出缓冲区，避免在 40 MS/s、1000 ms 等设置下因一次性生成 4000 万点而占用过多内存。

点击导出后，软件保存：

```text
output\reconstructed_signals\<name>\
  <name>.npy
  <name>_float32_iq.bin
  <name>.json
  <name>_preview.png
```

其中二进制文件为小端 `float32` 交织 `I,Q,I,Q,...`。这是通用复数 IQ 格式；实际信号源的专用波形格式需要根据最终回放设备另行转换。数字 IQ 仅保持信号间的相对幅度，绝对场强需要在信号源、功放、天线和试验场地组成的回放链路中标定。

## 设备回放

“设备回放”模块直接接收最近一次生成的重构结果，也可以点击“载入当前重构结果”手动刷新。
软件按回放参数缩放数字 IQ，并将数字峰值硬限制在 `0 dBFS` 以内，默认使用
`-1 dBFS` 以保留量化和链路余量。生成设备波形包后会得到 R&S `SMU-WV` 波形文件和
JSON 参数记录：

```text
output\playback_packages\<name>\
  <name>.wv
  <name>_playback.json
```

回放界面提供三种链路：

1. `SMW200A 内部 ARB（重构波形）`：将 `.wv` 上传到 SMW 的 `/var/user/`，设置中心频率、
   射频电平并启用 ARB；配置过程中 RF 始终保持关闭。
2. `IQR → SMW200A 数字 IQ（已有 IQR 波形）`：配置 SMW 数字基带输入，并通过 IQR
   Player 的 SCPI 命令选择 IQR 中已有的波形、设置单次或连续模式并启动回放。重构 RAW
   文件导入 IQR 需要 `IQR-K101` 选件；无该选件时应使用 SMW ARB 路径，不能把通用
   `.npy/.bin` 文件直接当作 IQR 波形。
3. `离线仿真（不连接设备）`：完整执行参数校验、波形包生成、预计输出和播放窗口预览，
   但不发送 SCPI 命令。

界面分别显示送入设备的 I/Q、正交合成等效波形，以及重构频谱与预计回放频谱。预计输出
按理想线性链路计算，并在图例中明确标注；导入分析仪或接收机采集的复数 NPY、或含 `I/Q`
两列的 CSV 后，软件改为显示实测反馈并计算相关系数和 RMS EVM。I/Q 合成图使用低显示
中频以便观察波形，设备实际仍按设定中心频率完成射频上变频。

RF 输出采用独立安全联锁：设备配置不会自动打开 RF，只有连接成功、波形配置完成、参数未
超过软件安全上限，并勾选已确认衰减器、功放和负载安全后，RF 按钮才可使用。绝对场强仍需
通过信号源、功放、天线和场强探头组成的实验室链路进行闭环标定。

## 命令行批量出图

分析所有 recording：

```powershell
python .\iq_analyzer\plot_iq.py --data-dir .\data --recording all --out-dir .\iq_analyzer\output
```

只分析一个文件组，例如 `miaofu869m`：

```powershell
python .\iq_analyzer\plot_iq.py --data-dir .\data --recording miaofu869m --out-dir .\iq_analyzer\output
```

只分析前 0.05 秒，适合快速预览：

```powershell
python .\iq_analyzer\plot_iq.py --data-dir .\data --recording miaofu869m --duration-sec 0.05
```

指定图类型：

```powershell
python .\iq_analyzer\plot_iq.py --data-dir .\data --recording miaofu869m --plots time spectrum constellation
```

## 输出内容

- `<name>_summary.txt`: 基本信息和幅度/功率统计；
- `<name>_time.png`: I/Q、幅度、相位随时间变化；
- `<name>_constellation.png`: IQ 星座散点图；
- `<name>_spectrum.png`: Welch PSD 频谱；
- `<name>_spectrogram.png`: 频谱图；
- `<name>_histogram.png`: I/Q 和幅度分布。

## 数据格式说明

当前数据头部显示：

- `TYPE:IQR-WV`
- `SECTORSIZE:8192`
- `RESOLUTION:16`
- `COMPONENTS:IQ`
- `CHANRATE0: 40000000.000`

因此代码按 `8192` 字节文件头后的小端 `int16` 交织 `I,Q,I,Q,...` 读取，并除以 `32768` 归一化为 `[-1, 1)` 附近的浮点 IQ。
